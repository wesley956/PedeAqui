# Compatibilidade sem PIX

WhatsApp não depende de PIX. Uma unidade com dinheiro/cartão presencial pode usar:
- saudação + link;
- atendimento humano;
- pedido recebido;
- produção/retirada quando aplicável;
- saiu para entrega/entregue quando aplicável.

Nenhum gate desta entrega liga PIX ou transforma pagamento online em requisito global.
