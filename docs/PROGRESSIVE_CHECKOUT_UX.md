# Checkout público progressivo

Issue lógica: **[301]**.

A sequência principal é identificação → recebimento → endereço quando houver entrega → pagamento → revisão. Retirada não solicita endereço. Benefícios são opcionais e ficam em divulgação progressiva para não interromper o caminho principal.

Cada etapa continua sendo salva pelas server actions existentes. A revisão final permanece obrigatória e revalida carrinho, operação da loja, identidade, entrega, forma de pagamento e benefícios antes de liberar a criação do pedido.

O layout usa tokens e controles touch-friendly, e a barra de progresso remove automaticamente a etapa de endereço para retirada. Nenhuma regra de checkout, pagamento, delivery ou growth foi alterada.
